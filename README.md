# DLT Desktop · 开奖数据分析与复盘

一款 Windows 桌面工具，把七个彩种的开奖历史、走势图、候选选号和历史回测放在同一个地方。普通版免费，双击 `DLTDesktop.exe` 即可使用。

## 能做什么

- **查开奖、看走势**。支持大乐透、双色球、七乐彩、七星彩、福彩 3D、排列 3、排列 5。按日期或期号查历史，查看号码频次、和值、奇偶和走势图。随包历史可离线查阅。
  <img width="1244" height="821" alt="image" src="https://github.com/user-attachments/assets/78170200-b7a7-433f-813a-71f1e5b2f5c6" />

- **选号和复盘**。按条件生成候选号码，保存后可与实际开奖对照。还可以对历史数据做回测，查看不同策略在同一段历史里的表现。
  <img width="1244" height="821" alt="image" src="https://github.com/user-attachments/assets/a0b43112-d6d4-40b1-b64c-5e731b2d0176" />

- **图表与报告**。会员可按套餐使用热力图、完整遗漏、共现矩阵、多窗口报告、数据导出和 AI 解读。AI 解读使用自行配置的服务。
  <img width="1244" height="821" alt="image" src="https://github.com/user-attachments/assets/24c20205-1bb0-4176-b8ad-eb7a63d1f649" />

- **地区分析**。各版本可导入自己的地区数据。SVIP 季卡起可查看和同步大乐透官方一等奖地区公告，按省查看中奖注数和分布。
  <img width="1244" height="821" alt="image" src="https://github.com/user-attachments/assets/2fe1d4c9-d3eb-46f3-a968-ed7b3150a351" />

- **模型研究**。SVIP 年卡和买断可做模型研究与逐期重训回测。
